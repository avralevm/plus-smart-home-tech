# Plus Smart Home Tech

Система для сбора и анализа данных от датчиков умного дома. На вход подаются данные датчиков, приложение — собирает эту информацию, обрабатывает и определяет, какие сценарии умного дома необходимо запустить.

---
## 🚀 Технологии

*   **Java / Spring Boot**: Основной стек для разработки бэкенд-сервисов.
*   **Spring Cloud**: Для реализации инфраструктурных паттернов в микросервисной архитектуре:
    *   *Service Discovery* (`discovery-server`)
    *   *Centralized Configuration* (`config-server`)
    *   *API Gateway* (`gateway-server`)
*   **Docker & Docker Compose**: Для контейнеризации и оркестрации сервисов в среде разработки.

---
## 🧩 Структура проекта

Проект состоит из нескольких основных модулей:

-   **commerce**: Модули, реализующие бизнес-логику платформы электронной коммерции.
    -   `delivery`: Сервис для управления доставкой заказов.
    -   `interaction-api`: API для взаимодействия между сервисами.
    -   `order`: Сервис для управления заказами.
    -   `payment`: Сервис для обработки платежей.
    -   `shopping-cart`: Сервис для управления корзиной покупок.
    -   `shopping-store`: Сервис для управления каталогом товаров.
    -   `warehouse`: Сервис для управления складом.
-   **infra**: Инфраструктурные сервисы, обеспечивающие работу микросервисной архитектуры.
    -   `config-server`: Сервер конфигурации для централизованного управления настройками приложений.
    -   `discovery-server`: Сервер обнаружения, позволяющий сервисам находить друг друга в сети.
    -   `gateway-server`: API-шлюз, единая точка входа для всех внешних запросов.
-   **telemetry**: Модули, отвечающие за сбор и обработку данных с датчиков умного дома.
    -   `aggregator`: Агрегатор телеметрических данных.
    -   `analyzer`: Анализатор телеметрических данных.
    -   `collector`: Сборщик телеметрических данных.
    -   `serialization`: Модули для сериализации данных.

## 🐳 Запуск проекта

Проект использует **Docker** для контейнеризации сервисов и баз данных.
Для локального запуска выполните команду в корневой директории проекта:

```bash
  # Команда соберёт образы всех сервисов и запустит их в Docker-контейнерах.
  docker-compose up --build
```
